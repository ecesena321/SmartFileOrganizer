# SmartFileOrganizer

SmartFileOrganizer is a small C++ project I developed to practice file operations and improve my programming skills.

The program helps organize files in a folder by moving them into different folders according to their extensions.

## What it does

- Takes a folder path from the user
- Shows which files will be moved before starting
- Sorts files into folders like Images, Audio, Videos and Documents
- Checks if a file with the same name already exists
- Allows the user to undo the move operation
- Shows the files left in the main folder after the operation

## Built with

- C++
- Filesystem library

## What I learned

While working on this project, I practiced using loops, conditions, vectors, file paths and basic error handling in C++.

This is one of my personal projects, and I plan to improve it as I learn more.
